Privacy Policy

Data the app receives from TikTok

  • Basic profile information of the authorizing account (user.info.basic).
  • An access token that allows uploading video drafts (video.upload).

How the data is used and stored

The token is stored only in a local file on the owner's computer and is used only to upload drafts to the same account. No data is sold, shared with third parties, or used for advertising or tracking.

Video processing

Videos are transcribed locally on the owner's computer. The text transcript is sent to the Anthropic API only to pick the best moments for clips; no TikTok account data is included.

Deleting data

Deleting the local token file, or removing the app's access in TikTok's settings, ends all access immediately. Since the owner is the only user, there is no other personal data to delete.
